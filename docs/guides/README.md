# 가이드 문서 안내

이 폴더의 문서는 **참고 자료**다. 스펙이 아니다.

- 기술 규칙의 단일 기준(SSOT)은 `CLAUDE.md`(저장소 루트)다.
- 기능 정의는 `docs/PRD.md`, 진행 순서·완료 판정은 `docs/ROADMAP.md`다.
- 이 폴더의 문서와 위 세 문서가 어긋나면 **`CLAUDE.md`가 우선**한다. 어긋나는 서술을 발견하면 이 문서를 고치되, 위 세 문서는 건드리지 않는다.
- 미설치 라이브러리를 예시 코드에서 그대로 `import`하지 않는다. `todo-frontend/package.json`의 실제 설치 상태를 먼저 확인할 것.
